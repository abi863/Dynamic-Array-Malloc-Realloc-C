# Dynamic Array Using malloc() and realloc() in C

## Description
This program dynamically allocates memory for an integer array using `malloc()`, increases its size using `realloc()`, adds new elements, and displays the complete array.

## Concepts Used
- Dynamic memory allocation
- `malloc()`
- `realloc()`
- Pointers
- Arrays and loops
- `free()`

## How to Run
```bash
gcc malloc_realloc.c -o malloc_realloc.exe
./malloc_realloc.exe
```

## Language
C
